## Como rodar
1. Instale o [Rojo](https://rojo.space) e o plugin do Rojo no Studio.
2. Na pasta do projeto: `rojo serve`.
3. No Studio: plugin Rojo → Connect. Depois, Play.

Ou abra a pasta no Claude Code com o MCP do Roblox Studio ativo e peça para sincronizar e testar (o `CLAUDE.md` explica tudo).
