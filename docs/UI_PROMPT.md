# ELEVATOR — UI/UX DESIGN SYSTEM (prompt original)

Act as a senior game UI/UX designer and Roblox interface developer.

Design and implement the complete UI/UX system for ELEVATOR.

## CREATIVE DIRECTION

The visual identity must combine:

* Premium minimalist game interface.
* Retro industrial elevator systems.
* Liminal atmosphere.
* Old digital displays.
* Institutional signage.
* Subtle analog technology details.

The UI must feel like it belongs to the physical world of ELEVATOR.

Avoid:

* Generic Roblox simulator interfaces.
* Excessive rounded cards.
* Neon gradients.
* Cartoonish icons.
* Generic horror UI.
* Excessive visual clutter.
* Unnecessary animations.

## COLOR SYSTEM

- Charcoal: #252725
- Old Ivory: #D6CBB5
- Dusty Sage: #A3A18A
- Warning Amber: #C77B55
- Fog White: #E7E2D7
- Emergency Red: #A83C38

## REQUIRED INTERFACES

1. Gameplay HUD.
2. Lobby interface.
3. Elevator control panel.
4. Floor introduction.
5. Objective and timer system.
6. Player elimination screen.
7. Spectator interface.
8. Checkpoint decision screen.
9. Results screen.
10. Shop.
11. Inventory and relic collection.
12. Hideout.
13. Settings.
14. Daily and weekly quests.

## HUD REQUIREMENTS

The HUD must be contextual.

Display only information relevant to the current gameplay state.

Include:

* Current floor.
* Survivors.
* Current objective.
* Countdown.
* Run rewards.
* Elevator streak.
* Contextual interaction prompts.

Different floors must be able to customize the objective presentation without creating completely separate HUD systems.

## UX REQUIREMENTS

* Mobile-first.
* Responsive across PC, mobile and tablet.
* Clear visual hierarchy.
* Accessible text sizes.
* Consistent iconography.
* Minimal interaction steps.
* Clear button feedback.
* Smooth transitions.
* Keyboard, controller and touchscreen support.

## DEVELOPMENT REQUIREMENTS

Before implementation, inspect the existing project.

Do not overwrite functional systems.

Create reusable UI components and a centralized design system.

Use appropriate Roblox UI objects and modular Luau scripts.

Keep game logic server-authoritative.

Separate visual presentation from gameplay logic.

Test the UI in multiple device resolutions.

## DELIVERABLE

First, create a complete UI/UX visual specification with wireframes and component states.

Then implement the interfaces incrementally.

Start with:

1. Gameplay HUD.
2. Lobby.
3. Elevator panel.
4. Floor introduction.
5. Checkpoint screen.

Do not implement every menu at once.

The final result should feel like a cohesive, professionally designed game, not a collection of unrelated UI screens.
